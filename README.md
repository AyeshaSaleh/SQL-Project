# 🗄️ SQL Analytics & Database Management (SQL Server)

This repository contains an SQL-based project focused on relational database design, data manipulation (DML), and complex analytical querying using **Microsoft SQL Server**. It showcases my ability to structure raw data into meaningful schemas and extract actionable insights using industry-standard T-SQL practices.

---

## 🎯 Project Overview
The projects within this repository focus on solving business-logic problems through structured data. Key areas include:
* **Database Schema Design:** Creating normalized tables (1NF, 2NF, 3NF) to reduce data redundancy.
* **Complex Data Extraction:** Using advanced joins, subqueries, and window functions.
* **Data Cleaning with T-SQL:** Standardizing records and handling null values directly within the database engine.

---

## 🛠️ Technical Skills Demonstrated
* **SQL Environment:** Microsoft SQL Server Management Studio (SSMS).
* **Dialect:** T-SQL (Transact-SQL).
* **Query Optimization:** Writing efficient queries and understanding execution plans for large datasets.
* **Relational Mapping:** Designing Entity-Relationship (ER) diagrams to visualize data flow.
* **Business Logic Implementation:** Creating views, stored procedures, and triggers to automate data tasks.

---

## 🔍 Key Analytical Workflows
* **Multi-Table Joins:** Combining customer, order, and product data to analyze high-value sales channels.
* **Aggregations & Filtering:** Utilizing `GROUP BY` and `HAVING` clauses to identify regional performance trends.
* **Window Functions:** Calculating running totals, moving averages, and ranking performance using `OVER` clauses.
* **CTE (Common Table Expressions):** Structuring complex queries for better readability and performance.

---

## 🚀 How to Use
1. **Clone** the repository.
2. **Open** Microsoft SQL Server Management Studio (SSMS).
3. **Connect** to your local or remote SQL Server instance.
4. **Import & Execute:** Open the `.sql` script files and execute them to generate the database schema and view analytical results.
